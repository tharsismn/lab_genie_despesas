# Laboratório Genie Space - Despesas Públicas de São Paulo

## 📋 Descrição

Este repositório contém um laboratório prático para construção de uma **Genie Space** no Databricks focada em análise de dados de despesas públicas do Estado de São Paulo.

## 🎯 Objetivo

Criar um ambiente conversacional que permita análises interativas sobre gastos públicos utilizando linguagem natural, sem necessidade de conhecimento em SQL.

## 🗂️ Estrutura do Projeto

* **LAB_GENIE_DESPESAS_SP.ipynb** - Notebook principal com todo o processo de preparação e configuração
* Exploração e preparação dos dados
* Configuração de tabelas no Unity Catalog
* Setup da Genie Space
* Exemplos de perguntas e validações

## 📊 Dados

O laboratório trabalha com dados de despesas públicas do Estado de São Paulo, incluindo:

* Órgãos e secretarias governamentais
* Categorias e tipos de despesas
* Valores empenhados, liquidados e pagos
* Períodos e datas das transações
* Informações sobre fornecedores

## 🚀 Como Usar

1. Clone este repositório
2. Importe o notebook no seu workspace Databricks
3. Configure o acesso ao Unity Catalog
4. Execute as células sequencialmente
5. Configure sua Genie Space seguindo as instruções

## 🛠️ Requisitos

* Databricks Workspace com Unity Catalog habilitado
* Acesso a SQL Warehouse ou Cluster
* Permissões para criar catálogos e schemas
* Genie Spaces habilitado no workspace

## 📝 Notas

* Este é um ambiente de laboratório para fins educacionais e de demonstração
* Siga as políticas de retenção do workspace (use tags RemoveAfter quando apropriado)
* Mantenha recursos em sua pasta pessoal (/Users/seu.email@databricks.com)
